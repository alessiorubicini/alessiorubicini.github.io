and tools for developers

Control Center for SwiftUI

SwiftUI package for iOS Control Center

Bring the iOS 26 Control Center experience into your apps. Native-feeling components, smooth gestures, and responsive layouts make building elegant, familiar controls effortless in SwiftUI.

Apple Intelligence for SwiftUI

SwiftUI package for Apple Intelligence UI

Integrating AI often breaks the native OS feel. This package mirrors Apple Intelligence design patterns and animations, allowing developers to build human-centered AI features that feel at home on Apple platforms.

Swift Sessions

Binary session types for Swift

Concurrent programming in Swift is prone to communication errors. Based on my Bachelor's thesis, this framework implements binary session types to ensure safe, structured, and reliable interactions in concurrent systems.

SF Symbols Picker for SwiftUI

SwiftUI package for SF Symbols selection

Users often need to choose icons from Apple’s vast library. This customizable picker simplifies SF Symbols selection for iOS and macOS apps, featuring full support for native SwiftUI bindings.

Location Picker for SwiftUI

SwiftUI package for location selection

Manual coordinate entry is a poor user experience. This tool provides an interactive map interface for SwiftUI, offering real-time coordinate selection and seamless integration via state bindings.

Pencil Drawer for SwiftUI

SwiftUI package for drawing

Implementing drawing features usually requires complex PencilKit boilerplate. This library simplifies the process with clean SwiftUI bindings, enabling smooth, interactive drawing with minimal setup.

Island Alerts for SwiftUI

SwiftUI package for Dynamic Island alerts

Standard alerts can be intrusive or outdated. This package brings eye-catching, customizable notifications to the Dynamic Island and Notch, blending perfectly with Apple’s modern interface language.
