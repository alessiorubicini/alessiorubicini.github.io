Ember

Fynn

Minimalist iOS finance app

Effortless money management, reimagined. Fynn lets you track expenses and income using natural language. No clutter, no charts, no complex menus. AI runs entirely on your device for fast, private, and intuitive financial tracking.

and packages for developers

Control Center for SwiftUI

SwiftUI package for iOS Control Center

Bring the iOS 26 Control Center experience into your apps. Native-feeling components, smooth gestures, and responsive layouts make building elegant, familiar controls effortless in SwiftUI.

Apple Intelligence for SwiftUI

SwiftUI package for Apple Intelligence UI

Create human-centered AI experiences in SwiftUI. This package mirrors Apple Intelligence’s design language, animations, and interaction patterns to make AI features feel intuitive and perfectly at home on Apple devices.

Swift Sessions

Binary session types for Swift

A robust framework for safe, structured communication in concurrent Swift systems. Implements binary session types to ensure reliable interactions. Built as my Bachelor’s thesis project.

Pencil Drawer for SwiftUI

SwiftUI package for drawing

Integrate drawing into your apps effortlessly. Pencil Drawer simplifies PencilKit usage with SwiftUI bindings, letting users draw smoothly and interactively with minimal setup.

Island Alerts for SwiftUI

SwiftUI package for Dynamic Island alerts

Add eye-catching alerts to the iPhone Dynamic Island or Notch. Supports multiple sizes and styles, fully customizable, blending seamlessly with Apple’s interface.

Location Picker for SwiftUI

SwiftUI package for location selection

Let users select geographic coordinates easily. Offers interactive maps, real-time coordinate display, and smooth SwiftUI integration via bindings.

SF Symbols Picker for SwiftUI

SwiftUI package for SF Symbols selection

Simplify SF Symbols selection in your apps. Provides a clean, customizable picker with full binding support for iOS and macOS.
